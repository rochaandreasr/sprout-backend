# 🌱 Sprout

> Uma plataforma de microcrédito e "vale-insumo" inteligente para o agronegócio, impulsionada por sensores IoT (ESP32-C3), IA conversacional e privacidade descentralizada (Solana, Cloak e Zcash).

## 🚀 Sobre o Projeto
Desenvolvido para o hackathon, o **Sprout** resolve o risco de crédito no campo transformando o financiamento agrícola em um "vale-insumo" restrito. O produtor rural não precisa lidar com criptomoedas ou telas complexas: ele interage de forma humanizada via WhatsApp com um assistente de IA, enquanto dados de sensores IoT garantem a saúde da safra de forma anônima e segura.

## 🛠️ Tecnologias Utilizadas
* **Back-end:** Node.js / JavaScript
* **Banco de Dados:** Supabase (PostgreSQL)
* **IoT:** ESP32-C3 SuperMini
* **Blockchain & Privacidade:** Solana, Cloak, Zcash

## 📂 Estrutura do Banco de Dados
O script SQL completo para criação das tabelas (producers, sensors, vouchers, merchants, transactions) está localizado na pasta `database/schema.sql`.
